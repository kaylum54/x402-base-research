# Due diligence: Cluster Protocol, Treasure (MAGIC and AI Frens) and Pocket Network (POKT) on x402 and Base (as of 2026-10-11)

> **Scope.** Three token-bearing projects that sell or launch through x402 on Base, profiled to help decide which to follow daily and how seriously to take each. No price or chart analysis. "The last six months" means 2026-04-11 to 2026-10-11. All sources were accessed on 2026-10-11 unless a different date is given. Claims that I could not confirm are labelled "unconfirmed", "company-reported" or listed under Gaps.
>
> **Method and conventions.** x402 figures are Base data from x402scan's public tRPC endpoints (the ones its website calls) and from the Coinbase Bazaar discovery API, pulled 2026-10-11; USDC amounts are converted from 6-decimal units. x402scan only tracks USDC settlements for these facilitators and recipients, so a payment made in another token does not appear. GitHub numbers come from the `gh` CLI (commits on default branches). On-chain checks used Base's public RPC. People are recorded only with public professional information; an X handle is recorded only when an official page, the person's own GitHub profile or an official link names it, with the source and my confidence. Sibling notes in this folder (`ecosystem_map_and_metrics.md`, `dd_data_ai_sellers.md`, `dd_x402_apps_and_trust.md`, `dd_token_experiments.md`) were used as leads and re-checked where I relied on them.

## 1. Cluster Protocol (CP)

> **Takeaway.** Cluster Protocol sells pay-per-request AI inference (a reseller gateway over third-party model providers) plus "agent run" tiers at $1, $5 and $15, all paid in USDC on Base through x402, and launched a CP token on 2026-09-02. It is a funded, named-CEO company (about $7.75M raised, company-reported), but its x402 volume, the largest by dollars among multi-buyer Base sellers after BlockRun, looks like an always-on fixed set of about 500 to 700 wallets that stopped on 2026-10-02, and the company's own token document says wallets that paid via x402 were eligible for its airdrop. I found no organic paying cohort.

### One-line
Cluster Protocol is a small AI-infrastructure company (issuer: Open Protocol Labs Ltd, British Virgin Islands) that resells AI model calls (chat, embeddings, images, speech, reranking, "autonomous agent" runs) through an OpenAI-style API that agents can pay per request in USDC over x402, and it also runs CodeXero, a browser tool that turns a prompt into an on-chain app. It launched a CP token on 2026-09-02. Its x402 registry entry describes none of this; the 402 challenges and OpenAPI file do. ([OpenAPI](https://api.clusterprotocol.ai/openapi.json), [token disclosure v1.0, 2026-08-31](https://hub.clusterprotocol.ai/public-disclosure), [x402 docs page](https://hub.clusterprotocol.ai/docs); all accessed 2026-10-11)

### x402 role
- **Seller / resource server** (main role). `/.well-known/x402` lists 9 resources; I confirmed with unpaid probes on 2026-10-11 that they return HTTP 402 with x402 v2 challenges on Base (`eip155:8453`), USDC, payTo `0x68396bD35874695AD86cd29410Bd80A550991a2B`. Prices: chat completions $0.003, embeddings $0.0005, rerank $0.001, speech-to-text $0.006, text-to-speech $0.015, image generation $0.02, agent execute $1.00, agent execute "Pro" $5.00 and "Max" $15.00 (Pro described as "extended reasoning, deeper tool use", Max as "long-horizon multi-agent orchestration"). The chat schema lets the buyer pin an upstream provider (examples: venice, groq, phala, redpill, zerog), which shows it is an aggregator. ([manifest](https://api.clusterprotocol.ai/.well-known/x402), [chat 402 challenge](https://api.clusterprotocol.ai/v1/chat/completions), [Pro](https://api.clusterprotocol.ai/v1/agents/execute/pro), [Max](https://api.clusterprotocol.ai/v1/agents/execute/max), probed 2026-10-11)
- **Token experiment** (secondary): the CP token disclosure counts "wallets that transacted on the network (including via x402)" as airdrop-eligible, which ties x402 payments directly to token distribution ([disclosure](https://hub.clusterprotocol.ai/public-disclosure)).
- Facilitator used: Coinbase (CDP) per x402scan transfer rows ([x402scan transfers API, pulled 2026-10-11](https://www.x402scan.com/api/trpc/public.transfers.list)). Not a facilitator, SDK or analytics project.
- Inconsistencies in the project's own files: the OpenAPI lists 7 paths (no Pro or Max) and says "500+ models" in one place and "40+" in another; the docs page shows two price tables that disagree (embeddings $0.0005 vs $0.001, speech $0.015 vs $0.01) ([OpenAPI](https://api.clusterprotocol.ai/openapi.json), [docs](https://hub.clusterprotocol.ai/docs)).

### Chains
Base is primary: x402 settlement is USDC on Base mainnet only, the whitepaper says the contracts are on Base, and the token is described as Base-native. The CP contract is deployed at the same address on BNB Chain and Mantle (Chainlink CCIP burn-and-mint design). CodeXero added a deploy target on GIWA Sepolia (Upbit's upcoming L2) on 2026-09-30; the roadmap names Arbitrum, other EVM chains and LayerZero routing for later. ([CPTOKEN README](https://github.com/clusterprotocol/CPTOKEN), [whitepaper](https://cluster-protocol.gitbook.io/whitepaper), [announcement 743](https://t.me/s/clusterprotocolann?before=744), [roadmap image](https://cluster-protocol.gitbook.io/whitepaper/roadmap))

#### x402 volume: how much of it looks like real paying use
**My estimate: close to zero identifiable organic demand (under about 10%, best guess near 0%).** No claim here is proof of who paid; each item is a pattern I measured or a statement the company made.

1. **The company ties x402 use to its token airdrop.** The 2026-08-31 disclosure lists airdrop eligibility as "CodeXero users, wallets that transacted on the network (including via x402), testnet and campaign participants, and dataset contributors", sets aside a 656M-CP "Campaign Reserve", and names "post-incentive activity declines" as a risk ([disclosure](https://hub.clusterprotocol.ai/public-disclosure)). Earlier campaigns used leaderboards and prize pools (see Track record).
2. **A fixed, always-on set of wallets.** From 2026-06-02 to 2026-10-01 the series shows 3,400 to 5,600 payments and 484 to 681 distinct payers every day; across the whole history daily buyers never exceed 681 and all-time buyers total 730. Buyer-days divided by distinct buyers is 88: the average wallet paid on 88 separate days. On 2026-09-30 and 10-01, 452 of 572 payers from the first day (79%) paid again the next day, each making about six payments a day (mostly 3 to 10), almost all in the same mix: roughly four or five $0.003 calls plus one $1, $5 or $15 agent run ([transfers, pulled 2026-10-11](https://www.x402scan.com/api/trpc/public.transfers.list)).
3. **Dollars come from the agent tiers, transactions from the cheapest calls.** On those two days, $0.003 calls were 74% of transactions but 0.3% of dollars; $1, $5 and $15 agent runs were 99.7% of the $5,991. The sibling note's full last-30-day paging gives the same shape: about $45K of $54.8K from $5 and $15 runs ([sibling note](dd_x402_apps_and_trust.md)).
4. **Metronome behaviour.** On 2026-06-03 to 06-10 each weekday shows 484 to 490 payments of exactly $1.00 from 484 to 488 distinct wallets (one payment per wallet), 6 on Saturday 06-06 and none on Sunday 06-07. After mid-June there is no weekend dip (average transactions per day: Tue 3,956, Sat 3,992, Sun 3,671). Real developer demand rarely looks like this.
5. **Switches on and off with company events.** Daily volume fell from 3,536 transactions on 2026-09-01 to 190 on TGE day 09-02, then about one a day for 13 days, then restarted at full strength on 09-15 (3,260 tx, 557 buyers), and ended on 2026-10-02 (152 tx, then one a day) with no product or price change announced.
6. **Wallet profile.** Of 30 random payer wallets active on 2026-09-30 or 10-01, 27 had never sent an on-chain transaction themselves (nonce 0), 9 held only dust ETH, and balances left were small and round-ish ($0.65 to $22; 14 of the 30 under $1.00). Payments used about 20 relayer addresses of the Coinbase facilitator. This fits purpose-made wallets that only sign payments; it does not show who funded them ([Base public RPC, checked 2026-10-11](https://mainnet.base.org)).
7. **The payee moves the money on.** The payTo wallet is a plain EOA that has sent 8,156 transactions and now holds $42.28 USDC and about 0.0096 ETH (2026-10-11), so revenue is swept elsewhere. I could not trace where (the public RPC rate-limited log queries), so a closed loop, where funds flow back to payers, is neither shown nor ruled out.
8. **The first 20 days are a script.** From 2026-05-20 to 05-31, 4,800 to 10,800 payments a day came from only 65 to 111 wallets for $24 to $804 a day, then the June cohort of about 500 wallets arrived overnight on 2026-06-02 (500 buyers, 4,529 tx).
9. **The company's own marketing uses the number** ("130,000 payment requests", "#4 on the Base Leaderboard by active users") ([recap](https://medium.com/feed/@clusterprotocol.io)).

**What would count as real:** the cheap $0.003 calls spread across many one-time wallets, which I did not see; a payer base that grows with product launches rather than campaign dates; or payments continuing after 2026-10-02. None of these showed up.

### Pace verdict
**Fast in announcements, opaque in engineering.** The channel posts nearly daily and added six models in two months, but the public code trail is two commits in six months and one 0.1.0 package, so a reader cannot check the shipping claims. Category leader BlockRun's ClawRouter repo logged 133, 40, 38, 36, 54 and 99 commits in April to September and more than 100 releases since 2026-04-11; the x402 Foundation repo logged 67 to 115 commits a month ([GitHub API, pulled 2026-10-11](https://api.github.com/repos/BlockRunAI/ClawRouter/commits)). A small AI-assisted team typically ships weekly commits and monthly releases in public; Cluster does not show that. Its own roadmap also slipped: TGE was due July and came on 2026-09-02, and CP billing and staking, planned for the same window, have not been seen.

### Green and red flags
- **Green:** named CEO and legal entity; a real, documented 51-risk-factor token disclosure; named institutional investors quoted in the funding release; third-party audit of the token contract; working 402 endpoints (probed 2026-10-11); major exchange listings (CoinGecko lists Coinbase Exchange, OKX, Bitget, Gate, MEXC, Bithumb).

### Verdict
**Speculative. Momentum: Slowing.** Cluster is a funded, legally organised company with a genuine but resold product, not a shell, and it knows how to pull exchange listings. But the headline claim, "the biggest x402 seller on Base", is a fixed set of wallets whose activity the company itself linked to its airdrop and which stopped the day after the last full campaign-style day, and the token currently does no work in that flow. Expect marketing and listings to continue (KBW, TOKEN2049, GIWA) while x402 usage stays near zero unless a new campaign restarts it; watch for CP-denominated billing or staking shipping, a public repo or changelog, and payments resuming from new wallets.

## 2. Treasure (MAGIC, AI Frens / Summon, x402 facilitator)

> **Takeaway.** Treasure is a five-year-old DAO that began as an Arbitrum NFT-gaming ecosystem, nearly ran out of money in April 2025, and rebuilt itself around AI characters; the x402 facilitator on Base is a small supporting utility for that pivot, not a separate bet. The pivot is real and governance-ratified, but the x402 piece is tiny ($400 USDC all-time, $8.25 in the last six months, nothing material since July), new character launches stopped after 2026-05-26, and the public engineering trail is almost empty. I found no real paying use of the facilitator.

### One-line

### Pace verdict
**Slow in public.** A small AI-assisted team in 2026 typically ships weekly commits and monthly releases; Treasure's public org logged one commit in six months, no releases, no blog post and no governance vote since February, and its x402 facilitator is still on x402 v1 while the ecosystem has moved to v2 (Cluster's and Pocket's live challenges are v2). ### Green and red flags
- **Green:** named, doxxed co-founder; open on-chain governance with 47 Snapshot proposals and long-form rationale; the AI pivot was ratified before it was built; live products; working facilitator (probed 2026-10-11); MAGIC has real liquidity in 100 Base pools; DAO reports "12 months in stables" runway (2026-02).
- **Red:** April 2025 near-insolvency ($8.3M burn against $2.4M cash, 15 layoffs, co-founder exit); six narrative changes in five years; the founder's own plan is to "pivot, pivot, and pivot again"; the DAO funds a startup founded by its own leader that wants no crypto branding and holds a non-voting 10%; turnout down to 23 voters; x402 usage essentially nil and v1-only; new character launches stopped; public engineering almost silent; Base MAGIC is 1.2% of supply; burn unverified; aggregator funding totals unreliable.

### Verdict
**Speculative. Momentum: Slowing** (the x402 facilitator itself: Stalled). Treasure is a real organisation with real governance and live consumer products, so it is not abandoned, but it is a DAO that survived a cash crisis by pivoting to whatever the next theme was, and its x402 work is a thin layer under an AI-character launchpad whose launches have fallen to zero since late May. As an explainer it is a good story about how a gaming DAO became an "AI agents plus x402" brand, not a source of x402 demand. Watch for new Summon launches, any visible MAGIC burn under TIP-61, a v2-compatible facilitator, and a Spellguard launch that pulls the founder's attention away from the DAO.
