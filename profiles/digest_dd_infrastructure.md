# Digest of x402 infrastructure projects on Base

Digest of `dd_token_facilitators.md` (file 1) and `dd_nontoken_infrastructure.md` (file 2), both researched 2026-10-11. Written for the report writer, in place of the raw notes. No new research was done. "Last six months" means 2026-04-11 to 2026-10-11. Sources were accessed 2026-10-11 unless a date is shown.

## Reading notes

- **Two usage measures that do not mix.** File 1 uses x402scan's public data: transfers sent by known facilitator addresses on Base, Solana and Polygon only; it hides facilitators under 100 tx in a window; USD = raw token units / 1e6 (https://www.x402scan.com/facilitators). File 2 could not read x402scan, so it uses the Base transaction count (nonce) of each facilitator address from the Base RPC (https://mainnet.base.org). A nonce counts every transaction the address sent, not only x402 settlements. Treat it as an activity gauge.
- **Counts are not demand.** Several facilitators show millions of transactions worth fractions of a cent (automation, load tests, token-mint loops). PayAI says so itself (https://blog.payai.network/x402-is-gaining-momentum-on-solana-thats-a-win-for-the-whole-ecosystem/).
- **Limits.** Web search quota ran out in both pieces of research. X and LinkedIn cannot be fetched. CryptoRank returned 403, RootData an empty page, Crunchbase 403. Funding and team claims rest on project pages, GitHub, CoinGecko and a few aggregators (AskSurf, CoinCodex, CoinCarp, TechFlow, VCBacked). The x402.org ecosystem page returned 404, so file 1 read the facilitator list from the `coinbase/x402` repo data.
- **People rule.** Only professional, public information. An X handle is recorded only when an official page links it, the person declares it (a GitHub `twitter_username` field counts as self-declared) or a Farcaster-connected account gives it. Pseudonyms are not tied to real names.
- **Pace benchmark.** The reference repo x402-foundation/x402 had 529 commits in the 26 weeks to 2026-10-11 (about 20 a week; file 1 says 67 to 115 a month) and `@x402/core` had 19 npm releases between 2026-04-11 and 2026-09-29 (https://github.com/x402-foundation/x402, https://registry.npmjs.org/@x402/core). The researchers expect a small AI-assisted team to commit weekly and release about monthly.
- **Scales.** Seriousness: Serious builder / Credible but small / Speculative / Likely abandoned. Momentum: Accelerating / Steady / Slowing / Stalled / Dead. Trend-hopping 1 to 5, where 5 means the project chases every narrative. "Unverified" marks where the notes could not confirm a claim.
- **Dune.** One shared dashboard (https://dune.com/hashed_official/x402-analytics) covers PayAI, Heurist, Ultravioleta DAO, Treasure and others. Meridian, Primer and AnySpend were not seen in its chart legend (page truncated). No Dune dashboard was found for any file 2 project (not searched after the quota ran out). The tracking cards leave Dune out; use this dashboard for the projects it lists.

## Coinbase's own facilitator (CDP) as the baseline

- **Price and scope.** First 1,000 on-chain transactions a month free, then $0.001; verification free. Chains: Base, Polygon, Arbitrum, World, Solana (+ testnets). Schemes `exact`, `upto`, `batch-settlement`. OFAC and KYT screening, Bazaar discovery, ERC-8021 builder codes. Its own undated claim: "more than 100 million transactions and $28 million" (https://docs.cdp.coinbase.com/x402/seller/facilitator.md).
- **Usage (x402scan, to 2026-10-10).** Lifetime 118.03M tx / $30.19M. Base, last 30 days: 1,965,296 tx / $232,816, with 29,911 buyers and 34,199 sellers. That is 90.4% of Base facilitator tx but 33.2% of Base USD (https://www.x402scan.com/facilitators).

## Group view

On Base, nobody in this group beats Coinbase's own facilitator on price or volume. CDP gives the first 1,000 on-chain transactions a month free, then charges $0.001, and it carried 90.4% of Base facilitator transactions in the last 30 days (1,965,296 tx, $232,816), against 1.1% for PayAI, 0.3% for Primer and 0.2% for Meridian. PayAI leads on delivery (303 public commits and 12 npm releases in six months, a dated price list, upstream x402 PRs), but its Base transactions fell from 8.95M in Jan 2026 to about 33K in Sep and it calls itself Solana-first. Merit Systems ($10M seed) and Crossmint ($23.6M round) also carry the "Serious builder" label, and both have moved attention away from x402: Merit cut x402scan features in August and put founder time into OpenInstinct, while Crossmint treats x402 as one payment rail. Stalling or stopped: thirdweb (a serious company, but one x402 commit since January), ampersend (no public SDK commit since 2026-06-23), x402.rs (none since 2026-07-13), Mogami (none since May), AnySpend and Relai, with AurraCloud, CodeNut and MCPay dead. Trend-hopping is highest (4/5) at Heurist, Meridian, Merit, Relai, AurraCloud, MCPay and OpenX402, and three of the four main token facilitators (Primer, Meridian, Heurist) moved to Robinhood Chain between July and September 2026, which the researchers read as a trend-hopping signal. Check PayAI daily (blog RSS, GitHub, x402scan), Primer and Merit weekly, and x402scan itself, because Merit is trimming the tool that most of these usage numbers come from. Treat every transaction count with care: micro-payment automation inflates them, and the notes could not verify most funding or team claims.
